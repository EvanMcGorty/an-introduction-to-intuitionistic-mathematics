# An Introduction to Intuitionistic Mathematics

This repo contains a single-file tutorial on Intuitionistic Mathematics, AnIntroductionToIntuitionisticMathematics.agda.

You can read through it in a web browser, or better yet download it and fill in the exercises for an optimal learning experience.

By doing so you will learn how to write programs and formal proofs in the programming language and proof assistant Agda.

There are no prerequesites to this tutorial, aside perhaps from being interested in programming and/or mathematics.
