# An Introduction to Intuitionistic Mathematics

This repo contains a single-file, exercise-focused tutorial on formal theorem proving with Intuitionistic Mathematics, AnIntroductionToIntuitionisticMathematics.agda.

You can read through it in your web browser, or better yet download it and fill in the exercises for an optimal learning experience.

By doing so you will learn how to write programs and formal proofs in the programming language and proof assistant Agda.

There are no prerequisites to this tutorial, aside perhaps from being interested in programming and/or mathematics.

Learning to state and prove propositions formally, especially in an unambiguous and machine-verifiable manner, is extremely rewarding and well worth the effort.
